## About Me

I'm a **Full-Stack Developer from Mauritania** focused on building practical, scalable, and user-focused applications.

My main stack is **JavaScript, React, Node.js, Express.js, and MongoDB**. I enjoy building projects from the frontend all the way to the backend, database, authentication, APIs, and deployment.

I'm continuously expanding my skills in **TypeScript, Next.js, PostgreSQL, Redis, Docker, WebSockets, cloud deployment, system design, and AI integration**.

I also have a professional background in **telecommunications and networking**, which has given me experience with complex production environments, troubleshooting, monitoring, reliability, and distributed systems.

I believe the best way to learn software engineering is to **build real projects, solve real problems, and keep improving**.
